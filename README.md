# 🌟 MOXXI 3.0 — ВКонтакте Бот

Полнофункциональный кроссплатформенный игровой и управляющий бот для бесед и личных сообщений ВКонтакте.

## 🚀 Основные возможности
- 👑 **10 Рангов администрации** (Лидер [10], Зам [9] ... Стажёр [1]) + иммунитет иерархии
- ⚔️ **PvP Дуэли и Кости** между игроками на монеты в беседах
- 💘 **Шипперинг (Пара дня)** с совместимостью и предсказаниями
- 🏰 **Кланы и Банды**: создание, казна, топ кланов
- 💍 **Браки, Семьи и Дети**: свадьба, развод, завести ребёнка
- 🐉 **Рейдовые Боссы** беседы (50 000 HP, совместная атака)
- 🏢 **Бизнесы и Пассивный доход**: кофейня, IT-гигант, космодром
- 🚗 **Автопарк и Гараж**: покупка авто от Lada Vesta до Bugatti Chiron
- 🐾 **Питомцы**: зоомагазин, прокачка и кормление
- 🃏 **Азартные игры**: 21 Очко, Краш, Казино, Рулетка, Монетка
- ⛏ **Интерактивный фарм**: Шахта и Рыбалка с редким дропом
- 🔮 **Ирис-утилиты**: «инфа», «кто», «характеристика», «выбери»
- 🛡 **Модерация беседы**: кик, варны (3/3 автокик), правила, приветствия
- 🆘 **Омниканальный мост Техподдержки** в Telegram
- 📦 **Система Лутбоксов** и Подарков
- 🎮 **Чат-Викторины (Квиз)**

## 📦 Установка и запуск
1. Клонируйте репозиторий:
```bash
git clone https://github.com/gaskimka-oss/MOXXI-VK.git
cd MOXXI-VK
```
2. Установите зависимости:
```bash
pip install -r requirements.txt
```
3. Скопируйте `.env.example` в `.env` и укажите ваш токен:
```bash
cp .env.example .env
```
4. Запустите бота:
```bash
python main.py
```
или дважды кликните `start.bat`.
